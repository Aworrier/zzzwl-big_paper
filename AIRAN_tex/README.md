# IEEE Conference Short Paper (Overleaf-ready)

This folder contains a compact 3--4 page English conference paper distilled from Chapter 5, aligned to IEEE conference template style.

## Structure

- `main.tex`: complete manuscript (all正文与图代码已合并在该文件)
- `refs.bib`: bibliography entries
- `figures/`: optional directory reserved for later external figure replacement

## Compile in Overleaf

1. Upload the entire `conference_short_paper` folder to Overleaf.
2. Set main file to `main.tex`.
3. Compile with `pdfLaTeX`.

## Notes

- Author blocks in `main.tex` are placeholders and can be replaced directly.
- References use IEEE style via `\bibliographystyle{IEEEtran}`.
