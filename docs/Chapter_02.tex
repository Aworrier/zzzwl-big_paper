\chapter{随机接入网络及其建模}
\label{chapter2: system model}

本章旨在构建全篇论文的研究基础，对相关理论背景、核心机制及系统模型进行系统阐述。章节内容安排如下：首先，回顾现有主流随机接入标准方案，重点分析面向 5G 的概率接入机制与面向非授权频段的载波侦听机制，在总结技术演进路线的同时揭示现有方案的局限性，从而引出本文的研究动机；其次，深入解析连续传输机制 ST 的基本原理，论证其在提升信道利用率方面的内在优势；接着，引入后续性能量化分析所需的核心数学工具，即离散时间休假排队理论；最后，为实现不同协议间性能的公平对比，统一构建包含网络拓扑、信道特性及业务假设的通用系统场景模型，并定义关键性能评估指标。

\section{随机接入标准方案}
\label{sec:standard_schemes}

本节从机理分析与数学抽象的视角，对现有随机接入协议的内在结构进行解构。这里聚焦于协议在 MAC 层的本质运作原理，并建立其与经典随机接入模型之间的对应关系。该抽象框架为后续连续传输机制设计第~\ref{chapter3: SAST }章和第~\ref{chapter4: CSMAST }章，以及 AI 多协议选择第~\ref{chapter5: ai_selector}章提供统一的理论基础。

\subsection{基于连接的5G NR随机接入过程}
\label{subsec:cba_mapping}
\begin{figure}[t]
	\centering
	\includegraphics[width=0.95\linewidth]{figure/chap2/5G NR标准随机接入过程.pdf}
	\caption{5G NR 四步/两步标准随机接入流程示意图}
	\label{fig:cba_access}
\end{figure}

5g NR 随机接入过程，从先前的 4G LTE 随机接入过程演变而来。在 5G NR 的基于连接的数据传输模式下，终端在初始随机接入成功后，由基站分配专用无线资源，并在连接期间进行数据传输。现提出的标准方案中存在四步接入和两步接入两种流程，前者在竞争阶段包含更多的握手消息以提高可靠性，而后者则通过合并前导码与数据包来降低接入时延。两种流程图表示如\ref{fig:cba_access}所示。

从接入机理上看，无论四步还是两步，都具有明显的两阶段结构：（1）竞争建立阶段：终端通过随机接入获得资源授权；（2）独占传输阶段：终端在被分配资源上进行连续数据发送。第一阶段与 Slotted Aloha 具有相同的概率竞争特征，而第二阶段则表现为无竞争的资源独占。

因此，可将该结构抽象为一种竞争预留模型，记为 $\text{CBA}(q, M)$，其中 $q$ 为接入阶段的竞争概率，$M$ 为一次竞争成功后可连续占用的传输时隙数。当 $M=1$ 时，该模型退化为标准 Aloha；当 $M>1$ 时，竞争成本可在多个数据包之间分摊，从而提升单位数据的有效吞吐效率。
因此，5G 基于连接的数据传输机制在 MAC 层抽象上可视为一种基于连接的 Aloha 实现。

\subsection{面向短报文传输的5G NR随机接入机制}
\label{subsec:sdt_mapping}
\begin{figure}[t]
	\centering
	\includegraphics[width=0.95\linewidth]{figure/chap2/5G NR SDT标准随机接入过程.pdf}
	\caption{5G NR 四步/两步 SDT 标准随机接入流程示意图}
	\label{fig:sdt_access}
\end{figure}
在 5G NR 的短数据传输 SDT 场景中，终端在无既有连接状态下需要首先通过随机接入建立初始通信。在四步 SDT 标准接入方案中，终端通过发送 Msg1 前导码发起接入，并在 Msg3 中传输短报文；而在两步 SDT 标准接入方案中，终端将前导码与数据封装于 MsgA 中一并发送。
尽管信令流程存在差异，但在初始接入阶段，多个终端在离散配置的 PRACH 时隙中独立发起发送请求。两种流程图表示如\ref{fig:sdt_access} 所示。


从 MAC 层视角，每个终端在一个接入机会内仅面临两种决策：发起发送或者保持静默。
该决策可抽象为一次伯努利试验，其发送概率记为 $q \in [0,1]$。不同终端之间的发送行为在统计意义上相互独立。
因此，短报文随机接入在 MAC 抽象层面可视为一种时隙化概率竞争机制，其行为结构与经典的 Slotted Aloha 模型一致，也就是节点在离散时隙中以概率 $q$ 发送，
当且仅当该时隙内恰有一个节点发送时，接入成功。
因此，在不考虑物理层调制、编码等实现细节的前提下，5G 短报文随机接入的接入结构可在理论上等价映射为 Slotted Aloha。

\subsection{NR-U中基于LBT的随机接入过程}
\label{sec:csma_mapping}

在 NR-U 场景中，终端在非授权频段发送数据前必须执行 LBT 机制。这里假设终端已经完成初始接入并进入 RRC\_CONNECTED 状态，且在后续数据传输过程中需要遵守 LBT 规则。根据 3GPP 规范\cite{3gpp38213}，LBT 可分为四种类型，分别为 Cat 1 至 Cat 4，其复杂程度与竞争控制能力逐级增强。
\begin{itemize}
    \item Cat 1：无需 LBT；
    \item Cat 2：固定持续时间的信道检测；
    \item Cat 3：随机退避但无指数扩展；
    \item Cat 4：带指数退避的随机退避机制。
\end{itemize}
其中，Cat 4 引入了随机退避与竞争窗口扩展，其结构最接近经典 CSMA/CA。因此，本节重点分析 Cat 4 机制的流程如图\ref{fig:lbt_process}所示，即

\begin{figure}[t]
\centering
\includegraphics[width=0.9\linewidth]{figure/chap2/5G NR标准LBT过程.pdf}
\caption{NR-U中基于LBT的随机接入流程}
\label{fig:lbt_process}
\end{figure}

\begin{enumerate}[label=步骤\arabic*：, leftmargin=*, itemsep=1ex]

	\item 确定信道接入优先级与参数。终端在发起传输前，根据业务 QoS 要求选择信道接入优先级类别 CAPC。每个 CAPC 对应一组预定义的 LBT 参数，包括延迟持续时间参数 $m_p$、竞争窗口最小值 $CW_{\min}$、最大值 $CW_{\max}$，以及最大信道占用时间 MCOT。
    MCOT 受监管约束限制，用于保证与其他系统的公平共存。

	\item 竞争窗口更新与退避计数初始化。  
    终端根据上一轮传输结果更新竞争窗口 $CW$：
    \begin{itemize}
        \item 若传输成功或为初始传输，则 $CW = CW_{\min}$；
        \item 若传输被判定为失败（例如未收到 HARQ-ACK 或检测到冲突），则
        $CW \leftarrow \min(2CW+1, CW_{\max})$。
    \end{itemize}
    随后在整数区间 $[0, CW]$ 内均匀随机选择退避计数值 $N$。
	
	\item 执行延迟持续时间检测。  
    在开始退避计数前，终端必须检测信道在连续时间$T_d = 16\mu s + m_p \times 9\mu s$
    内保持空闲（典型 5 GHz 配置）。若期间检测到信道忙，则需等待信道重新空闲，并重新执行完整的延迟持续时间检测。

	\item 退避计数与 CCA 时隙监听。  
    终端在 $9\mu s$ 的 CCA 时隙上执行退避计数：
    \begin{itemize}
        \item 若信道空闲，则 $N \leftarrow N-1$；
        \item 若信道忙，则冻结计数器，
        待信道重新空闲并重新满足步骤 3 的延迟持续时间要求后恢复倒计时。
    \end{itemize}
    当 $N=0$ 时，终端获得发送机会。

	\item 数据发送与 MCOT 约束。  
    终端在获得信道后进行数据传输，
    传输持续时间不得超过该 CAPC 对应的 $T_{mcot,p}$。
    传输结束后，
    根据成功或失败结果更新 $CW$，
    为下一次接入做准备。
\end{enumerate}

从接入机制的本质出发，Type 4 LBT 与经典 CSMA/CA 在 MAC 层具有一一对应的竞争逻辑：二者均遵循先侦听后发送的信道占用原则，均通过随机退避计数分散并发发送时机，并在失败后通过竞争窗口扩展抑制后续冲突概率。因此，在以时隙化 CCA、理想碰撞信道和饱和或非饱和队列业务为前提的理论分析框架下，NR-U 的 LBT 过程可等效抽象为 CSMA 型随机接入网络。该抽象保留了影响吞吐量、时延与公平性的主要竞争行为，同时忽略物理层调制、频谱监管细节与跨系统共存策略等次要差异，因此可作为后续 CSMA 网络建模与性能推导的合理基础。

综上，无论是基于连接的接入过程、面向短报文的接入过程，还是基于 LBT 的竞争接入过程，都包含一个共同的结构特征，即随机竞争阶段与后续连续占用阶段之间的衔接关系。后续第~\ref{chapter3: SAST }章和第~\ref{chapter4: CSMAST }章正是在这一抽象认识基础上，分别对两类典型机制中的连续传输策略展开专门建模与分析。为避免与后续章节重复，连续传输机制的具体流程、建模细节与性能分析不在本章展开，仅保留上述概念性引导。

\section{通用系统场景与模型假设}
\label{sec:general_system_model}


为构建具有普适性与可扩展性的理论分析框架，并为后续章节中不同接入机制 SAST 与 CSMAST 的性能比较提供统一分析基准，本文首先建立一个抽象化的上行随机接入网络系统模型。在保证物理拓扑结构一致性的前提下，通过对节点行为机制进行差异化建模，实现对多种接入范式的统一刻画与对比分析。

本章节考虑一个包含 $n$ 个同质终端节点和一个中心基站的上行通用无线随机接入系统，如图~\ref{fig:system_model} 所示。所有节点通过共享无线信道向同一接收机发送数据，接收机负责信号接收、译码与反馈。系统中仅接收机设计接收结构，而节点之间不存在显式协调或直接通信机制。
\begin{figure}[t]
	\centering
	\includegraphics[width=0.9\linewidth]{figure/chap2/通用系统场景.pdf}
	\caption{通用系统场景示意图}
	\label{fig:system_model}
\end{figure}

需要特别说明的是，尽管后续各章节的分析重点不同，但接收机与节点之间的物理拓扑关系在全文中保持一致。不同章节之间的差异主要体现在节点侧接入策略与控制逻辑的设计，而非系统结构本身的改变。具体而言：

\begin{itemize}
	\item 在第~\ref{chapter3: SAST }章中，基站主要承担集中接收与反馈功能，终端节点的行为建模侧重于概率发送与连续传输的传输策略，系统分析聚焦于基于连续传输的时隙 ALOHA 机制的性能刻画；
	
	\item 在第~\ref{chapter4: CSMAST }章中，基站仍作为统一接收实体，而终端节点行为进一步扩展为侦听、退避和发送相结合的竞争式接入过程，系统模型引入载波监听机制和连续传输，用以刻画 CSMAST 协议的动态行为和性能分析；
	
	\item 在第~\ref{chapter5: ai_selector}章中，在保持统一拓扑结构不变的前提下，研究重点转向不同协议与参数组合下的性能评估与接入协议智能切换机制。此时节点配备有多重接入协议策略，其具体接入行为被抽象为可切换的策略集合，分析核心从单一接入协议到多接入协议策略集合的性能。
\end{itemize}

在上述通用系统场景框架下，具体系统假设如下：

\begin{itemize}
	\item 网络拓扑与流量模型：网络由 $n$ 个统计特性相同的同质节点组成。各节点的数据包到达过程相互独立且同分布。
	
	为了便于第\ref{chapter3: SAST }章和第\ref{chapter4: CSMAST }章的排队论解析推导，本文在理论分析模型中假设各节点的包到达过程均服从参数为 $\lambda$ 的伯努利过程，其中 $\lambda$ 的单位为包每时隙，即每个节点在每个时隙有新数据包到达的概率为 $\lambda$，且不同时隙的到达事件相互独立，因而系统的总到达率为 $\hat{\lambda} = n\lambda$。服从这种特性的流量也可称为均匀流量。均匀流量的简化假设使得系统动态可精确刻画为离散时间马尔可夫链，便于应用休假排队理论进行闭式求解。
	
	然而，现实通信场景中的到达过程通常具有显著的非平稳性与多尺度统计特征，仅以均匀流量建模难以全面反映实际业务特性。
	因此，除均匀到达外，本文进一步引入突发型与周期型两类流量。在第\ref{chapter5: ai_selector}章中，我们采用统一流量特征向量	$\mathbf{x}_{\text{traffic}}=[\hat{\lambda},\ \mathrm{BI}_{\mathrm{net}},\ \mathrm{BI}_{\mathrm{node}},\ \Psi_{\mathrm{net}},\ \Psi_{\mathrm{node}}]^{\top}$对其进行刻画。三类流量形态定义如下：
	\begin{itemize}
		\item 均匀到达流量 $U$：$\mathrm{BI}_{\mathrm{net}}\approx 0$ 且 $\Psi_{\mathrm{net}}\approx 0$，对应近似泊松到达；
		\item 突发到达流量 $B$：$\mathrm{BI}_{\mathrm{node}}>0$ 且 $\Psi_{\mathrm{node}}\approx 0$，采用 MMPP 或批量到达过程刻画事件驱动型集中上报；
		\item 周期到达流量 $P$：$\mathrm{BI}_{\mathrm{net}}$较小且 $\Psi_{\mathrm{net}}>0$，刻画周期或同步上报业务。
	\end{itemize}
	流量特征的完整定义与计算公式见第\ref{chapter5: ai_selector}章表~\ref{tab:traffic_feature_def}，具体参数配置与采样策略见该章仿真实验部分。
	
	\item 时隙结构与同步：系统采用离散时间模型，时间轴被划分为连续且等长的时隙。时隙长度被标准化为传输一个固定长度数据包所需的时间。系统假定所有节点保持严格的时钟同步，因此所有数据包的传输只能在每个时隙的起始时刻发起。
	
	\item 信道模型：假设信道为理想无噪声信道，采用标准碰撞信道模型。当且仅当一个时隙内只有一个节点进行传输时，接收机才能成功解码数据包；若多个节点在同一时隙并发传输，则发生信号叠加导致碰撞，所有涉及的数据包均传输失败且无法恢复。
	
	\item 反馈机制：假设基站提供完美且即时的反馈。节点在每个传输时隙结束时，能够立即通过确认或否定确认信令获知该次传输是否成功。分析中忽略反馈信道的传输错误及传播延迟。
	
	\item 数据包与信令开销：假设系统中传输的所有数据包具有固定长度，且完整占用一个时隙。相比之下，控制信令的数据量极小，其传输时间在分析中被视为瞬时完成，或已包含在时隙保护间隔内，不额外占用数据传输资源。
	
	\item 缓存队列与网络状态：每个节点配备容量无限大的缓冲区，数据包在缓冲区中遵循先进先出原则。在此假设下，数据包不会因缓存溢出而丢失，但可能会在队列中积压。根据节点缓存的积压情况，我们将网络运行状态划分为两类用于后续分析：
	\begin{itemize}
		\item 饱和状态：假设节点缓存始终非空，即 $p_{ne}=1$，节点始终有数据包待传。此状态用于推导系统的理论吞吐量极限。
		\item 非饱和状态：节点缓存可能为空，即 $p_{ne} < 1$。此状态更符合实际流量场景，用于评估系统的稳态时延与实际吞吐量。
	\end{itemize}
\end{itemize}

基于上述通用假设，后续章节将在统一场景下展开递进分析：第~\ref{chapter3: SAST }章聚焦 SAST 机制下 Aloha 型接入的吞吐量与时延等性能特性，第~\ref{chapter4: CSMAST }章分析 CSMAST 机制下的性能边界；在此基础上，第~\ref{chapter5: ai_selector}章进一步面向多业务与动态负载环境，综合吞吐量、时延、公平性与信令开销等指标，研究多协议智能切换与参数自适应优化问题。

\section{基于休假排队理论的分析方法}
\label{sec:vacation_queuing_theory}

本节仅给出后续分析所需的抽象数学框架。考虑一个离散时间随机过程，其状态在两类阶段之间交替演化，分别记为忙期 $B$ 与休假期 $V$，相应周期记为
\begin{equation}
C = B + V,
\end{equation}
其中 $B,V,C\in\{0,1,2,\ldots\}$ 或 $\{1,2,\ldots\}$，具体取值范围由后续模型设定决定。以下仅讨论这些随机变量的分布表示、变换工具及其与马尔可夫链之间的关系。

对任意离散非负整数随机变量 $X\in\{0,1,2,\ldots\}$，其概率质量函数定义为
\begin{equation}
p_X(k)=\Pr\{X=k\},\qquad k=0,1,2,\ldots
\end{equation}
相应的概率生成函数定义为
\begin{equation}
G_X(z)=\mathbb{E}[z^X]=\sum_{k=0}^{\infty}p_X(k)z^k,\qquad |z|\le 1.
\end{equation}
PGF 是本文后续推导的基本工具，其原因在于它能够同时编码分布信息与矩信息。由 PGF 可恢复 PMF：
\begin{equation}
p_X(k)=\frac{1}{k!}\left.\frac{\mathrm{d}^k G_X(z)}{\mathrm{d}z^k}\right|_{z=0}.
\end{equation}
若 $G_X(z)$ 在 $z=1$ 处可导，则有
\begin{equation}
\mathbb{E}[X]=G_X'(1),
\end{equation}
\begin{equation}
\mathbb{E}[X(X-1)]=G_X''(1),
\end{equation}
\begin{equation}
\mathrm{Var}(X)=G_X''(1)+G_X'(1)-\bigl(G_X'(1)\bigr)^2.
\end{equation}
因此，一旦得到 $B$、$V$、$C$ 或队列长度变量的 PGF，便可进一步得到其均值、方差及更高阶矩。

PGF 对和与复合运算尤其方便。若 $X$ 与 $Y$ 相互独立，则
\begin{equation}
G_{X+Y}(z)=G_X(z)G_Y(z).
\end{equation}
若 $S=\sum_{i=1}^{N}X_i$，其中 $X_i$ 独立同分布且与 $N$ 相互独立，则
\begin{equation}
G_S(z)=G_N\bigl(G_X(z)\bigr).
\end{equation}
因此，当一个随机变量可表示为随机长度区间上的独立增量之和时，其 PGF 往往可写成某种复合形式。这是后续求解忙期内累积量、休假期内累积量以及周期内累积量的基本依据。

下面引入嵌入时刻上的队列过程。设 $Q_m$ 和 $P_m$ 分别表示第 $m$ 个忙期起点与终点处的队列长度，$A_{V,m}$ 和 $A_{B,m}$ 分别表示第 $m$ 个休假期与忙期中的到达量，$S_m$ 表示第 $m$ 个忙期中的离开量，则一般地可写为
\begin{equation}
Q_{m+1}=P_m+A_{V,m},
\end{equation}
\begin{equation}
P_m=\bigl(Q_m-S_m\bigr)^+ + A_{B,m}.
\end{equation}
若在给定当前状态后，$A_{V,m}$、$A_{B,m}$ 和 $S_m$ 的条件分布仅依赖于当前状态而与更早历史无关，则序列 $\{Q_m\}$、$\{P_m\}$ 或其联合过程构成离散时间嵌入马尔可夫链。此时，休假排队问题可转化为该嵌入马尔可夫链的稳态分布问题。

设嵌入马尔可夫链在稳态下满足
\begin{equation}
\pi_k=\Pr\{Q=k\},\qquad k=0,1,2,\ldots,
\end{equation}
则其 PGF 为
\begin{equation}
G_Q(z)=\sum_{k=0}^{\infty}\pi_k z^k.
\end{equation}
因此，求解稳态 PMF 与求解稳态 PGF 是等价的。实际推导中，通常先利用递推关系、平衡方程或条件分解得到 $G_Q(z)$ 的函数方程，再由其导出 $\pi_k$ 或矩信息。

当休假期内部仍包含多个子状态，且这些子状态之间按照有限状态随机规则切换时，可进一步引入吸收马尔可夫链。设休假期的内部状态由瞬态集合组成，其瞬态子转移矩阵记为 $\mathbf{T}$，初始分布记为 $\boldsymbol{\alpha}$，吸收事件对应休假期结束。则休假期长度 $V$ 的 PMF 满足
\begin{equation}
\Pr\{V=k\}=\boldsymbol{\alpha}\mathbf{T}^{k-1}(\mathbf{I}-\mathbf{T})\mathbf{1},\qquad k\ge 1,
\end{equation}
其 PGF 为
\begin{equation}
G_V(z)=z\,\boldsymbol{\alpha}(\mathbf{I}-z\mathbf{T})^{-1}(\mathbf{I}-\mathbf{T})\mathbf{1}.
\end{equation}
这表明，吸收马尔可夫链可视为求取休假期 PMF 与 PGF 的一种矩阵化方法；而一旦得到 $G_V(z)$，又可继续代回嵌入马尔可夫链的函数方程中，完成更高层随机变量的求解。

从方法结构上看，休假排队模型、PGF 和马尔可夫链三者之间的关系可以概括如下：休假排队模型负责给出随机变量的分解结构，嵌入马尔可夫链负责描述关键观测时刻上的状态更新，PGF 负责将分布递推转化为函数方程并提取矩信息；当内部阶段结构较复杂时，吸收马尔可夫链进一步给出忙期或休假期分布的解析表示。后续章节将在这一抽象框架下，根据具体模型定义 $B$、$V$、$Q_m$、$P_m$、$A_{V,m}$、$A_{B,m}$ 和 $S_m$ 的具体形式，并由此完成各类解析推导。

\section{关键性能指标及问题}
\label{sec:performance_metrics}

为了全面评估所提机制的有效性，并与现有标准方案进行公平对比，本章统一定义以下关键性能指标，涵盖效率、时延、公平性与开销四个维度。

\subsection{吞吐量指标}

吞吐量是衡量系统有效传输能力的核心指标,本文细分为接入吞吐量与数据吞吐量两类：

\begin{itemize}
	\item 接入吞吐量 $\lambda^a_{out}$：定义为单位时间内成功传输的队首数据包或接入请求的平均数量，单位为包每时隙。该指标反映了系统处理并发接入请求的能力。
	
	\item 数据吞吐量 $\lambda^d_{out}$：定义为单位时间内信道成功传输的所有数据包数量的平均值，其中包含连续传输的后续包，单位为包每时隙。该指标衡量系统的有效负载传输效率。
\end{itemize}

\subsection{时延指标}

时延直接影响用户体验与服务质量，本文区分接入时延与端到端数据包时延：

\begin{itemize}
	\item 接入时延 $D_a$：定义为一个数据包从到达队首开始，到其成功被基站接收所经历的时间，单位为时隙。该指标主要体现竞争接入的等待成本，包含碰撞重传与退避等待时间。在节点视角的休假排队模型中，接入时延等于休假期长度的期望值。
	
	\item 数据包时延 $D_p$：定义为数据包从生成时刻进入缓存队列，直到被成功传输完毕并离开系统的全过程时延，单位为时隙。该指标包含排队等待时间和接入服务时间，直接反映端到端用户体验。
\end{itemize}

\subsection{公平性指标}

在多用户竞争环境中，资源分配的公平性直接影响系统的稳定性与用户满意度。本文采用 Jain 公平性指数 JFI 作为统一的公平性度量：

\begin{equation}
\text{JFI} = \frac{\left(\sum_{i=1}^{n} x_i\right)^2}{n \cdot \sum_{i=1}^{n} x_i^2}
\end{equation}

其中 $x_i$ 表示第 $i$ 个节点在观测时间窗口内获得的资源份额（可以是成功传输的数据包数量、占用的时隙数、或获得的吞吐量）。JFI的取值范围为 $[1/n, 1]$，其中 $1/n$ 表示最不公平情况（仅一个节点占用全部资源），$1$ 表示完全公平（所有节点获得相同资源）。

在本文分析中，我们重点关注短期公平性，即短时间观测窗口内的资源分配公平性。这主要有三方面原因：一是连续传输机制允许单个节点连续占用信道，可能导致短期内的不公平现象；二是实时业务对短期时延抖动敏感，长期统计公平性无法反映瞬时服务质量；三是短期公平性能够捕捉协议在动态流量变化下的瞬态行为。第\ref{chapter4: CSMAST }章和第\ref{chapter5: ai_selector}章将采用滑动窗口法计算不同时间尺度下的 JFI，以评估 SAST 与 CSMAST 机制在公平性方面的权衡。

\subsection{信令开销指标}

控制信令开销是随机接入系统的重要成本，直接影响能量效率与频谱利用率。为保证后文不同协议在信令开销维度上的可公平比较，本文以 3GPP 规范中必须出现的信令交互过程为统计对象，并采用统一归一化口径：将一次必要的上下行信令交互记为 1 个归一化信令单位。

在该口径下，不同协议的信令交互逻辑统一为：
\begin{itemize}
	\item CBA 协议对应如图\ref{fig:cba_access}所示的基于连接的四步随机接入流程，完整接入过程包含 Msg1 至 Msg4 四次必要交互，以及连接配置确认的第五次交互，因此每次接入尝试产生 4 至 5 个归一化信令单位；
	\item SA 协议对应如图\ref{fig:sdt_access}所示的两步 SDT 接入流程。无论单次接入尝试成功或失败，均包含 MsgA 与 MsgB 两次必要交互，因此每次接入尝试都会产生 2 个归一化信令单位；
	\item SAST 协议对应如图\ref{fig:flow_sast}所示的改进型两步 SDT 流程。队首包接入阶段沿用两步 SDT 的两次必要交互，接入成功后的连续发送阶段不再重复前导竞争，仅保留必要反馈交互，因此可在多包传输下摊薄单位数据的信令成本。
\end{itemize}

基于上述统一计量规则，本文定义以下两个指标：

\begin{itemize}
	\item 信令开销 $S$：定义为单位时隙内产生的归一化信令单位数，刻画协议控制面资源消耗强度。
	
	\item 信吞比 STR：定义为信令开销与数据吞吐量的比值，用于衡量单位有效传输能力对应的信令代价：
	\begin{equation}
	\mathrm{STR} = \frac{S}{\lambda_d},
	\end{equation}
	其中 $\lambda_d$ 为数据吞吐量（包/时隙）。STR 越小表示在获得同等数据吞吐时所需信令越少，信令效率越高。
\end{itemize}

% 度量单位的统一说明：本文在理论分析中通常以次数或归一化时隙数作为信令开销的基本单位，便于解析求解；在仿真验证与实际对比中，则采用比特数或归一化比特数作为统一度量单位，以便与 5G 等标准方案进行公平对比。两种度量方式可通过信令包的固定长度进行线性转换。

通过上述四类指标的综合评估，本文能够在效率、时延、公平性与开销等多个维度全面刻画所提连续传输机制的性能特征，并为后续章节的理论分析与仿真实验提供统一的评价基准。
