\chapter{致谢}

暮去朝来，光阴荏苒，须臾间却已是三年过去。如今毕业在即，不禁感慨万千。在师长同学的指导陪伴下，于“白云山高，珠江水长”的旋律轻吟之中，我得以窥见科学研究这座巍峨高山的瑰丽一隅。回顾三年求学经历，对那些曾经帮助过我，激励过我，为我指点迷津的人们，我的心中满怀感激。

首先，我衷心感谢我的导师孙兴华老师。感谢孙老师带领我在科研上初窥门径。您在科研与工作中一丝不苟和精益求精的态度让我领略到优秀科研人员的素养与担当；您缜密的思维习惯和精妙科研方法让我受益匪浅；您的包容与悉心培养更是令我感到关怀备至。衷心祝愿孙老师在工作与生活中心想事成，万事遂顺。

其次，感谢詹文老师和王玺钧老师对我科研和学习上的指导与帮助。感谢220实验室与同寝的各位同学，感谢文锐、晶亮、坤洪、津骏、奕全、源宏在生活和学习上的陪伴与帮助。感谢方明和嘉华师弟在科研路上的互相帮助与扶持，谢谢你们的陪伴。还要感谢电通学院18级的辅导员与全体研究生同学，谢谢各位对我班委工作的支持与鼓励。同窗有你，与有荣焉。

最后，感谢我的父母和哥哥姐姐，你们在背后默默的帮助给了我莫大的鼓励与支持，在我面对困难与迷茫之时，助我走出了状态的低谷。也感谢自己的坚持，努力与耕耘终有回报。
